# Aashirwad Synthetics website

This is the independent, static version of the Aashirwad Synthetics digital visiting card.

## Edit the website

Open `site-content.js` and change the text inside quotation marks. This single file controls:

- contact details and business hours
- WhatsApp greeting
- address, Maps, Instagram and catalogue links
- About text and business values
- product names, types and specifications

To replace the logo, upload a new file at `assets/aashirwad-logo.webp` using the same filename.

To update the downloadable contact card, edit `assets/aashirwad-synthetics.vcf`.

After a saved change reaches the `main` branch, GitHub Pages republishes the website automatically.
